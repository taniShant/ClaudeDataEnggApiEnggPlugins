# BUK UX Design Standards

> **Placeholder — owned by BUK UX Practice.**

---

## Areas to Cover

- Interaction design principles (clarity, feedback, error prevention)
- Journey design conventions — step count, progress indicators, exit points
- Screen flow patterns — happy path, error path, empty states
- Form design — field ordering, validation feedback, inline help
- Navigation patterns — back/forward, deep linking, session recovery
- Mobile-specific interaction patterns (touch targets, gestures)
- Research-driven heuristics — usability test findings, common failure patterns
- Accessibility considerations at the design stage (complement to `accessibility` skill)
