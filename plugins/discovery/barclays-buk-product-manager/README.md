# barclays-buk-product-manager

> **Status: Draft**

Turns problem statements into executable requirements, acceptance criteria, increment priorities, and success measures. Facilitates Consumer Duty and programme governance artefacts.

## Workflow Position

```
Problem Statement → Product Manager → UX Designer / Solution Architect
```

## Dependencies

- `buk-standards` — provides `consumer-duty` and `governance` skills

## Agents

| Agent | Purpose |
|---|---|
| `product-manager-agent` | Produces requirements, AC, priorities, success measures, and governance flags |
