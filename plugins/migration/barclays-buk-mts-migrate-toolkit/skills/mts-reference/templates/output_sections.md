# Output Section Templates

Templates for the four overview documentation files generated by the MTS documentation plugin.

---

## architecture-overview.md

```markdown
# Architecture Overview

## Technology Stack
Table: Spring Boot version, Java version, build tool, packaging, framework (MCA), database(s), messaging

## Application Layers
Mermaid component diagram showing:
- REST layer (controllers)
- Filter chain (in order)
- Service layer
- Helper layer
- EBS integration (doService calls)
- External systems (databases, MQ, mainframe)
Use ACTUAL class names from discovery data.

## Servlet Filter Chain
Table: Order | Filter Class | Purpose

## REST Endpoints
Table: HTTP Method | Path | Controller Class | Handler Method | Description

## Database Configuration
Per datasource: type (Oracle/DB2), JNDI name, pool settings, usage

## MQ Configuration
Queue manager, queues, connection factory details

## EBS/EGS Dependencies
Table: Artifact | Group ID | Version | Jar Type | Sources Available | Purpose

## Spring Configuration
XML config structure, imported configs, key bean definitions

## External Service Bindings
Table from services.properties: Service Name | Implementation Class
```

## service-inventory.md

```markdown
# Service Inventory

## doService Call Summary
Total count, breakdown by category (mainframe-touching / reference-data-only / framework)

## Complete Service Inventory
Table with columns:
| # | Service Name | Method | Mainframe Txn | File:Line | Request DTO | Response DTO | EBS JAR | Category | Per-Service Doc |

One row per doService call. Service names and method names must be the RESOLVED string values, not constant references.
Mainframe Txn column: transaction name(s) for mainframe-touching services (e.g., TDLQCU, TDLLCM); N/A for reference-data-only.
Link to corresponding service-doc-*.md file in Per-Service Doc column.

## EBS JAR Matrix
Table: EBS JAR | Jar Type | Services Provided | Source JAR Available | Key Classes
```

## code-journeys.md

```markdown
# Code Journeys

## Overview
Orchestration map showing how REST endpoints route to doService calls.
Cross-references per-service docs for detailed sequence diagrams.

## Journey Summary
Table: # | Endpoint | Final Service Call | Category | Chain Depth

## Journeys Per Endpoint
Group by endpoint. For each doService call, show call chain text with file:line refs.
Cross-reference per-service doc instead of duplicating sequence diagrams.
For non-doService endpoints, include a brief Mermaid diagram.

## Execution Order
Text tree showing sequential/conditional ordering of all doService calls within each endpoint.

## EBS Service Summary
Cross-reference table: Service | Method | Called From | Journey #
```
