# MCA1 to MCA2 Pattern Mapping Reference (Behavior-Preservation Strategy)

> **This file is superseded by `transformation-mapping.md`** which contains the complete
> behavior-preservation pattern mapping with 12 patterns + Part I-M amendments.
> This file is retained for backward compatibility.

This reference uses the **behavior-preservation** migration strategy: all MCA1 **framework**
patterns are replaced with MCA2 equivalents, while all **business logic** is preserved with
`@MCA2-*` markers.

For the complete pattern reference including before/after code examples, dependency mapping,
and Pilot 2 amendments (typed vs untyped, multi-domain, caching, void patterns, test matrix),
see **[transformation-mapping.md](transformation-mapping.md)**.

For the migration stub catalog (24 stubs, IOLContextAdapter, graduation guide), see
**[migration-stubs.md](migration-stubs.md)**.
