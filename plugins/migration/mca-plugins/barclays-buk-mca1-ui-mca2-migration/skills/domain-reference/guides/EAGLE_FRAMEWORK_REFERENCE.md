# Eagle Framework (mca-eagle-scripts) Reference

## Overview
**Version**: 0.0.0
**Package**: @barclays/mca-eagle-scripts
**Type**: CLI build tool and React app scaffolding framework
**Purpose**: Create and build MCA2 React applications with minimal configuration
**Base Dependencies**: Webpack 4.35.2, Babel 7.5.5

## CLI Commands

### Installation
```bash
npm install -g @barclays/mca-eagle-scripts
eagle create myapp
```

### Available Commands

1. **develop** - Start development server with HMR
   ```bash
   eagle develop
   eagle develop -- --webpack-config-path=./custom.js
   ```

2. **test** - Run Jest tests
   ```bash
   eagle test
   eagle test -- --watch
   eagle test -- --coverage
   ```

3. **build** - Create production build in /dist
   ```bash
   eagle build
   eagle build -- --webpack.presets=analyze
   ```

4. **lint** - Run ESLint validation
   ```bash
   eagle lint
   eagle lint -- --fix
   ```

5. **create** - Generate new React/TypeScript app
   ```bash
   eagle create myapp
   ```

## Configuration Files

### 1. eagle-config.js
Main Eagle Framework configuration file:

```javascript
module.exports = {
  devServerMiddlewares: ["mockServer/middleware.js"],
  port: 8080, // optional, defaults to 8080
  simulateHost: true, // simulate FullServe environment
};
```

### 2. webpack.config.js (Optional Override)
Custom Webpack configuration:

```javascript
const webpackConfigFunction = require('@barclays/mca-eagle-scripts/webpack.config.js');

module.exports = (args) => {
  const webpackConfig = webpackConfigFunction(args);
  // Override properties
  return webpackConfig;
};
```

### 3. .eslintrc.js
Extends Eagle's ESLint configuration:

```javascript
module.exports = {
  extends: ['./node_modules/eagle-scripts/.eslintrc.js'],
};
```

### 4. jest.config.js
Jest configuration:

```javascript
const jestConfig = require('eagle-scripts/jest.config');
module.exports = jestConfig;
```

### 5. babel.config.js
Babel transpilation configuration:

```javascript
// Preset environment and React support
module.exports = {
  presets: [
    ['@babel/preset-env', {...}],
    '@babel/preset-react',
  ],
};
```

### 6. tsconfig.json (TypeScript projects)
```json
{
  "extends": "eagle-scripts/tsconfig"
}
```

## Webpack Configuration System

### Preset Architecture
Eagle uses a preset-based Webpack configuration system:

**Default Presets** (src/config/presets/defaults/):
- `copy-plugin.js` - Copy static assets
- `file-loader.js` - Handle image/font files
- `jsx.js` - Babel JSX transformation
- `metadata.js` - Build metadata plugin
- `middlewares.js` - Dev server middleware
- `mini-css-extract-plugin.js` - CSS extraction
- `typescript.js` - TypeScript support

**Optional Presets** (src/config/presets/optional/):
- `analyze.js` - Bundle analysis with webpack-bundle-analyzer

### Enabling/Disabling Presets
```bash
eagle build --webpack.presets=analyze
eagle build --webpack.presetsExclude=copy-plugin
```

### Webpack Mode Configuration
```bash
eagle build --webpack.mode=production
eagle build --webpack.mode=development
```

## Development Server Middleware

### Middleware Configuration
Create middleware files to extend dev server:

**Function Middleware**:
```javascript
module.exports = function(req, res, next) {
  console.log(req.path);
  next();
};
```

**Object Middleware with init()**:
```javascript
module.exports = {
  init: function(app) {
    app.get('/somepath', function(req, res) {
      res.send({});
    });
  },
};
```

### Mock Server Example
Create mockServer/middleware.js for API mocking:

```javascript
module.exports = function(req, res, next) {
  if (req.path === '/api/data') {
    res.json({ data: 'mocked' });
  } else {
    next();
  }
};
```

## CLI Arguments and Options

### Webpack Arguments
- `--webpack.mode` - production, development, none
- `--webpack.presets` - Add optional presets
- `--webpack.presetsExclude` - Exclude default presets
- `--webpack-config-path` - Custom config file path (relative or absolute)

### Jest Arguments
- `--jest-config-path` - Path to jest.config.js
- All Jest CLI options supported

### ESLint Arguments
- `--eslint-config-path` - Path to .eslintrc.js
- All ESLint CLI options supported

### Eagle Configuration Arguments
- `--eagle-script-config` - Path to eagle-config.js
